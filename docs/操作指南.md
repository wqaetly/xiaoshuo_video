## 一、快速开始

### 1.1 首次使用 - 一键启动

```powershell
# 双击运行，或在命令行执行：
start_webui.bat
```

脚本会自动完成：
- 创建虚拟环境
- 安装所有依赖
- 安装 FFmpeg（如果缺失）
- 启动 Web 界面

启动成功后，浏览器访问：**http://127.0.0.1:7860**

### 1.2 准备工作

在开始之前，请确保：

| 检查项 | 说明 |
|--------|------|
| 小说文件 | 准备好 `.txt` 格式的小说文件 |
| Ollama 服务 | 用于生成分镜（可选，有默认配置） |
| 视频API密钥 | 即梦AI 或 可灵AI 的密钥（用于生成视频） |

## 二、Web界面详细使用

Web界面分为 8 个功能模块，按左侧导航栏切换：

### 2.1 项目管理（📁 项目）

这是你的起点，用于创建和管理项目。

#### 创建新项目

1. 点击左侧 **📁 项目**
2. 填写项目信息：
   - **项目名称**：给项目起个名字，如"春溅"
   - **上传小说**：点击上传你的 `.txt` 小说文件
   - **视频风格**：选择风格
     - `anime` - 动漫风格（推荐）
     - `realistic` - 写实风格
     - `illustration` - 插画风格
     - `chinese_fantasy` - 中国玄幻风格
3. 点击 **创建项目**

#### 打开已有项目

1. 在项目列表中选择项目名称
2. 点击 **打开项目**
3. 界面会显示项目状态信息

### 2.2 分镜编辑（🎬 分镜）

分镜是视频的"剧本"，定义每个场景的内容。

#### 生成分镜

> **注意**：生成分镜需要在"生成"页面操作，分镜Tab只用于查看和编辑。

1. 先切换到 **⚙️ 生成** 页面
2. 选择阶段为 `storyboard`
3. 点击 **开始生成**
4. 等待 AI 分析小说并生成分镜（可能需要几分钟）
5. 完成后切换回 **🎬 分镜** 页面查看结果

#### 加载和查看分镜

1. 打开项目后，点击 **🎬 分镜**
2. 点击 **加载分镜** 按钮加载已生成的分镜数据

#### 查看和编辑分镜

生成完成后，你会看到场景列表：

| 列 | 说明 |
|----|------|
| 序号 | 场景顺序 |
| 场景ID | 唯一标识，如 `scene_1_001` |
| 时长 | 该场景的视频时长 |
| 描述 | 场景的视觉描述 |
| 状态 | pending/completed/failed |

**编辑场景**：
1. 点击某个场景行
2. 在右侧编辑面板修改：
   - 时长（秒）
   - 视觉描述
   - 对话内容
   - 镜头类型（static/pan/zoom等）
3. 点击 **保存修改**

**调整顺序**：
- 拖拽场景项可调整顺序
- 调整后点击 **保存排序**

**筛选场景**：
- 搜索框：按关键词搜索
- 状态筛选：全部/待处理/已完成/失败
- 章节筛选：按章节过滤

### 2.3 角色管理（👤 角色）

管理小说中的角色信息和配音设置。

#### 查看角色

1. 点击 **👤 角色**
2. 查看自动提取的角色列表

#### 编辑角色

每个角色可以设置：
- **名称**：角色名字
- **性别**：male/female/unknown
- **配音**：选择语音音色
- **外观描述**：用于生成角色图像

### 2.4 生成控制（⚙️ 生成）

这是核心功能，控制视频生成流程。

#### 开始生成

1. 点击 **⚙️ 生成**
2. 选择生成阶段：
   - `full` - 完整流程（推荐）
   - `storyboard` - 仅生成分镜
   - `characters` - 仅生成角色
   - `images` - 仅生成图像
   - `audio` - 仅生成配音
   - `video` - 仅生成视频
   - `compose` - 仅合成最终视频
3. 可选设置：
   - **断点续传**：勾选后从上次中断处继续
   - **跳过失败场景**：遇到错误继续处理其他场景
   - **失败阈值**：失败比例超过此值时停止
4. 点击 **开始生成**

#### 查看进度

- 进度条显示当前进度
- 日志区域显示详细信息
- 状态显示：运行中/完成/错误

### 2.5 预览（👁️ 预览）

预览生成的内容。

#### 预览类型

- **单场景**：选择场景ID，预览该场景的图片/音频/视频
- **完整视频**：预览最终合成的视频

#### 操作

1. 选择预览类型
2. 选择场景或章节
3. 点击 **刷新预览**
4. 查看图片、播放音频/视频

### 2.6 设置（🔧 设置）

配置服务地址和参数。

#### 本地服务设置

| 设置项 | 默认值 | 说明 |
|--------|--------|------|
| Ollama URL | http://localhost:11434 | LLM服务地址 |
| Ollama Model | glm4:9b | 使用的模型 |
| ComfyUI URL | http://localhost:8188 | 图像生成服务 |
| CosyVoice URL | http://localhost:9880 | 语音合成服务 |

#### API设置

| 设置项 | 说明 |
|--------|------|
| 视频提供商 | jimeng（即梦）或 kling（可灵） |
| API密钥 | 对应平台的密钥 |
| 使用闲时 | 开启后使用低价时段 |

#### 视频参数

| 设置项 | 选项 |
|--------|------|
| 分辨率 | 1280x720 / 1920x1080 |
| 帧率 | 24 / 30 / 60 |

修改后点击 **保存设置**。

### 2.7 任务队列（📋 任务）

管理后台任务。

#### 功能

- 查看所有任务状态
- 批量重新生成（图像/音频/视频）
- 批量删除场景
- 批量重置状态
- 清除已完成任务

### 2.8 视频剪辑（🎞️ 剪辑）

对生成的视频进行后期编辑。

## 三、命令行使用

如果你更喜欢命令行，可以使用以下命令：

### 3.1 激活环境

```powershell
# 进入项目目录
cd C:\study\wqaetly\blog\xiaoshuo_video

# 激活虚拟环境
.\.venv\Scripts\Activate.ps1
```

### 3.2 常用命令

#### 创建项目

```powershell
python -m src.main create --name "项目名" --novel "小说文件路径" --style anime
```

参数说明：
- `--name`：项目名称（必填）
- `--novel`：小说文件路径（必填）
- `--style`：风格，可选 anime/realistic/illustration/chinese_fantasy

示例：
```powershell
python -m src.main create --name "春溅" --novel "txt\欠二两笔墨债 闲听梅雨窗外.txt" --style anime
```

#### 运行生成

```powershell
# 完整生成
python -m src.main run --project "项目名"

# 断点续传（从上次中断处继续）
python -m src.main run --project "项目名" --resume

# 只运行某个阶段
python -m src.main run --project "项目名" --phase storyboard
python -m src.main run --project "项目名" --phase images
python -m src.main run --project "项目名" --phase audio
python -m src.main run --project "项目名" --phase video
python -m src.main run --project "项目名" --phase compose

# 并行模式（更快）
python -m src.main run --project "项目名" --parallel
```

#### 查看状态

```powershell
# 查看项目状态
python -m src.main status --project "项目名"

# 列出所有项目
python -m src.main list

# 详细列表
python -m src.main list --detail
```

#### 导出项目

```powershell
# 导出为ZIP
python -m src.main export --project "项目名" --output "./导出目录"

# 导出为文件夹
python -m src.main export --project "项目名" --output "./导出目录" --format folder

# 包含临时文件
python -m src.main export --project "项目名" --output "./导出目录" --include-temp
```

#### 清理文件

```powershell
# 清理临时文件
python -m src.main clean --project "项目名" --temp

# 清理输出文件
python -m src.main clean --project "项目名" --output

# 清理所有生成文件
python -m src.main clean --project "项目名" --all

# 跳过确认
python -m src.main clean --project "项目名" --all --force
```

#### 批量处理

```powershell
# 批量处理多个项目
python -m src.main batch --projects "项目1,项目2,项目3"

# 批量处理指定阶段
python -m src.main batch --projects "项目1,项目2" --phase images

# 并行批量处理
python -m src.main batch --projects "项目1,项目2" --parallel
```

#### 启动Web界面

```powershell
# 默认启动
python -m src.main ui

# 指定地址和端口
python -m src.main ui --host 0.0.0.0 --port 8080

# 创建公共链接（可外网访问）
python -m src.main ui --share
```

## 四、完整工作流程示例

以下是一个完整的使用示例：

### 步骤1：准备小说文件

将小说保存为 `.txt` 文件，放在 `txt` 目录下：
```
txt\我的小说.txt
```

### 步骤2：启动工具

```powershell
start_webui.bat
```

### 步骤3：创建项目

1. 打开浏览器 http://127.0.0.1:7860
2. 在"项目"页面：
   - 项目名称：`我的小说`
   - 上传小说文件
   - 选择风格：`anime`
3. 点击"创建项目"

### 步骤4：生成分镜

1. 切换到"分镜"页面
2. 点击"生成分镜"
3. 等待完成（约2-5分钟）

### 步骤5：检查和调整分镜

1. 查看生成的场景列表
2. 如有需要，编辑场景描述、时长等
3. 保存修改

### 步骤6：配置API密钥

1. 切换到"设置"页面
2. 填入视频API密钥（即梦或可灵）
3. 保存设置

### 步骤7：开始生成

1. 切换到"生成"页面
2. 选择"full"（完整流程）
3. 勾选"断点续传"（推荐）
4. 点击"开始生成"

### 步骤8：等待完成

生成过程可能需要较长时间，取决于：
- 场景数量
- 网络速度
- API响应时间

你可以随时查看进度，如果中断，下次可以断点续传。

### 步骤9：预览和导出

1. 切换到"预览"页面
2. 选择"完整视频"
3. 播放预览
4. 满意后，在项目目录找到最终视频：
   ```
   data\projects\我的小说\output\final_video.mp4
   ```

## 五、常见问题解答

### Q1: 启动失败，提示找不到Python

**解决方案**：
1. 确保已安装 Python 3.10+
2. 安装时勾选"Add Python to PATH"
3. 重启命令行窗口

### Q2: 分镜生成失败

**可能原因**：
- Ollama 服务未启动
- 模型未下载

**解决方案**：
```powershell
# 启动Ollama
ollama serve

# 下载模型（如果没有）
ollama pull glm4:9b
```

### Q3: 图像生成失败

**可能原因**：
- ComfyUI 未启动
- 显存不足

**解决方案**：
1. 启动 ComfyUI
2. 如显存不足，使用低显存模式：`python main.py --lowvram`

### Q4: 视频生成失败

**可能原因**：
- API密钥未配置或无效
- 账户余额不足

**解决方案**：
1. 检查 `.env` 文件中的密钥
2. 登录即梦/可灵平台检查余额

### Q5: 如何断点续传？

如果生成中断：
- Web界面：勾选"断点续传"后重新开始
- 命令行：`python -m src.main run --project "项目名" --resume`

### Q6: 生成的视频在哪里？

最终视频位置：
```
data\projects\{项目名}\output\final_video.mp4
```

中间文件位置：
```
data\projects\{项目名}\images\    # 场景图片
data\projects\{项目名}\audio\     # 配音文件
data\projects\{项目名}\videos\    # 场景视频
```

### Q7: 如何修改视频风格？

1. 在"设置"页面修改默认风格
2. 或创建项目时选择不同风格
3. 也可以编辑 `config\settings.yaml`

### Q8: 如何使用自己的配音？

1. 将音频文件放入 `data\projects\{项目名}\audio\`
2. 命名格式：`{场景ID}.wav`
3. 跳过TTS阶段，直接运行合成
